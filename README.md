# 🎬 Studio Ghibli Fan Site

A beautiful, responsive fan website dedicated to Studio Ghibli — the legendary Japanese animation studio behind iconic films like *Spirited Away*, *My Neighbor Totoro*, and *Princess Mononoke*.

## ✨ Features

- **Home** – Welcome section with a hero banner and social media links
- **About** – Profile of Hayao Miyazaki, co-founder of Studio Ghibli
- **Movies** – Showcase of 9 iconic Ghibli films with descriptions
- **Contact** – A contact form to get in touch
- Responsive navigation with a mobile hamburger menu

## 📁 Project Structure

```
Studio-Ghibli/

└── asset/
    ├── css/

    ├── js/

    └── images/         # Movie posters and studio imagery
```

## 🚀 Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/DulaniWanigasekara/Studio-Ghibli.git
   ```
2. Open `index.html` in your browser — no build step required.
